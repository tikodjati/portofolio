# Portofolio Security Engineer (Next.js)

## Menjalankan
    npm install
    npm run dev      # buka http://localhost:3000

## Mengubah isi
Edit `data/content.js` (nama, skill, sertifikasi, project, writeup, pengalaman, kontak).
Gaya tampilan ada di `app/globals.css`.

## Deploy
- Vercel: push ke GitHub, import repo di vercel.com.
- GitHub Pages / static: `npm run build`, upload isi folder `out/`.
